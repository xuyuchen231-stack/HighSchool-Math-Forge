# Python 科学绘图与几何图规范
优先 Matplotlib + NumPy/SymPy；图应由明确方程、点坐标、几何构造或用户给定数据生成，不使用随机曲线假冒真实结果。`scripts/plot_examples.py` 包含抛物线及其切线、分段函数/渐近线、单位圆、二项分布示例。

1. 先定义数学对象与范围，计算关键点（顶点、零点、交点、切点）并核验坐标；在图注写出方程、参数、定义域和示意/精确属性。
2. 不连续函数分段采样，屏蔽禁值；不要用折线连接竖直渐近线两侧。
3. 坐标轴单位明确，等比例坐标适用于欧氏几何；三维图应说明投影可能造成视觉误差，证明不能依赖视图。
4. 统计图必须标注数据来源、样本量、频数/频率、分箱或分布假设。不可把模拟数据称为真实高考统计。
5. 输出矢量 PDF/SVG（LaTeX 引用优先 PDF），必要时提供 PNG 预览；使用 `bbox_inches='tight'` 防裁切。
6. 绘图代码与图一起交付，固定参数、随机种子（如使用模拟），禁止不可复现的手工修饰。
7. 中文字体缺失时使用英文图例，不可输出乱码；颜色不是区分曲线的唯一方式，应配线型或标注。
