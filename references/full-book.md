# 完整试卷教辅成品验收
建议顺序：封面→目录→原卷（逐页保留）→答案速查→逐题详解→知识点系统讲解→错题与迁移练习→索引与审校记录。题目解析与对应知识讲解尽量相邻，不要另附一个脱离题号的空泛知识清单。

逐题模板：【答案】【审题与条件】【思路】【逐步推导】【第二种验算】【知识点从零精讲】【易错原因】【变式训练】。每道选择题逐选项解释，每个小问独立给出过程。数学图在原卷后附精确重绘图与图中证据标记；不得覆盖原卷原图。必要时对原图做独立标注副本。

内容质量优先于页数。一般整卷零基础精讲会超过20页解析，但不可机械凑页数。正式验收需：所有题解完整、公式可复算、图可复现、页面逐张审阅、未解决问题为零。交付 PDF + LaTeX 源码 + Python 绘图脚本 + 审校报告。
